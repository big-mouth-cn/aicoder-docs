# 使用 Codex 接入 AICoder

本指南帮助你完成一条最短的使用路径：**安装 Codex Desktop / CLI → 注册 AICoder 并创建 API Key → 将 Provider 设置为 AICoder**。

AICoder 基于 sub2api 提供服务，官网是 [https://aicoder.work](https://aicoder.work)。本指南中的 API Key、模型和接口地址均使用 AICoder 控制台提供的信息。

## 按顺序开始

1. [下载安装 Codex Desktop / CLI](./install)：选择桌面界面或终端方式。
2. [注册 AICoder 账号和 API](./account)：注册账号，获取 API Key 和接口信息。
3. [将 Provider 设置为 AICoder](./provider)：使用 CC-Switch，或手动修改配置。

完成后，你就可以在 Codex 中通过 AICoder 发起编程任务。
